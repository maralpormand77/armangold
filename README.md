# 🪙 داشبورد هوشمند و تحلیلی روند رشد طلا و مسکوکات (Arman Gold Dashboard)

سامانه جامع، پویا و مکانیزه برای پایش، تحلیل و پیش‌بینی قیمت طلای ۱۸ عیار، انواع سکه و انس جهانی با معماری پیشرفته **مدل ترکیبی سه‌گانه (Tri-Hybrid Ensemble)** و پایگاه‌داده تحلیلی **PostgreSQL**.

---

## 🌟 قابلیت‌های کلیدی سامانه

1. **مدل پیش‌بینی یکپارچه سه‌گانه (Tri-Hybrid Ensemble)**:
   * **افق ۱ ماهه**: مدل‌سازی شتاب آنی و نوسانات با هوش مصنوعی شبکه عصبی عمیق **LSTM**.
   * **افق ۲ تا ۵ ماهه**: روند تطبیقی مومنتوم نقدینگی و میانگین متحرک نمایی (**EWMA**).
   * **افق ۶ تا ۱۲ ماهه**: چرخه‌های فصلی ۱۰ ساله طلا و تورم ساختاری.
2. **پایگاه‌داده تحلیلی PostgreSQL**:
   * جدول سری زمانی بهینه `gold_price_ticks` همراه با شاخص‌های تحلیلی حباب و اسپرد مظنه.
   * نماهای خودکار (SQL Views) برای محاسبه میانگین‌های **هفتگی**، **ماهانه**، **فصلی** (بهار، تابستان، پاییز، زمستان) و **سالانه**.
   * استخراج کندل‌های OHLC ساعتی و روزانه برای تحلیل تکنیکال و یادگیری ماشین.
3. **بروزرسانی خودکار و ابری ۲۴ ساعته (Serverless Automation)**:
   * بدون نیاز به روشن بودن کامپیوتر یا باز بودن مرورگر.
   * پشتیبانی کامل از **GitHub Actions** جهت استعلام خودکار هر ۳۰ دقیقه و بروزرسانی خودکار مخزن.
4. **طراحی واکنش‌گرا و مدرن (PWA Ready)**:
   * سازگار با کامپیوتر، تبلت و موبایل با اعداد استاندارد انگلیسی (`0-9`).
   * قابل استقرار رایگان روی **GitHub Pages**، **Vercel**، **Render** و **Netlify**.

---

## ⚙️ راه‌اندازی و فعال‌سازی سرویس خودکار ابری (GitHub Actions)

این مخزن به گونه‌ای پیکربندی شده است که سرورهای گیت‌هاب هر ۳۰ دقیقه یک‌بار به صورت کاملاً خودکار و رایگان اجرا می‌شوند:

1. به تب **Settings** ریپازیتوری در گیت‌هاب بروید.
2. از منوی سمت چپ به مسیر **Secrets and variables > Actions** بروید.
3. روی **New repository secret** کلیک کنید:
   * **Name**: `DATABASE_URL`
   * **Value**: آدرس اتصال دیتابیس ابری PostgreSQL شما (مثلاً از [Neon.tech](https://neon.tech) یا [Supabase.com](https://supabase.com)).
4. از تب **Actions** گردش‌کار «بروزرسانی خودکار هر ۳۰ دقیقه قیمت طلا» را فعال یا به صورت دستی تست کنید.

## 💻 اجرای محلی (Local Development)

### اجرای تحلیل پیشرفته داده‌های لحظه‌ای:
```bash
python analyze_postgres.py
```

### اجرای دستی استعلام و بروزرسانی دیتابیس و داشبورد:
```bash
python update_live_price.py
```

### اجرای دائم در سیستم شخصی (در پس‌زمینه):
* اجرای فایل `شروع_سرویس_خودکار_۳۰دقیقه.bat` یا `اجرای_مخفی_در_پس‌زمینه.vbs`
